Honda ECU Remap Android — Alpha 0.5

Included:
- Load BIN and XDF using Android document picker.
- Parse XDF table names, dimensions, Z addresses, bit widths, decimal places, and Z-axis math expressions.
- Display/modify values using supported simple linear XDF equations.
- Read/write multi-byte values using XDF DEFAULTS lsbfirst setting (must be validated against TunerPro).
- Export a new BIN copy; source file is not overwritten.
- Basic USB VID/PID detection for FTDI devices.
- GitHub Actions workflow builds debug APK.

Not implemented:
- Full XDF equation engine and linked RPM/TPS axis headers.
- Checksum calculation/correction.
- FTDI serial communication, ECU read/write, flashing, DTC scan, live data, or recovery.

Safety: do not flash edited files. Validate displayed values against TunerPro and establish checksum/protocol/recovery before any ECU write.
